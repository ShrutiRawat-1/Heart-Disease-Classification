# Heart Disease Classification Using Logistic Regression

## Project Overview

This project explores the use of supervised machine learning to classify the presence of heart disease based on patient health and diagnostic attributes.

The project was developed to gain practical experience with data exploration, preprocessing, machine learning model training and evaluation using Python and Scikit-learn.

## Objective

The objective of this project was to build a basic classification model using Logistic Regression and understand the workflow involved in developing a machine learning model for a binary classification problem.

## Tools & Technologies

- Python
- Pandas
- Scikit-learn
- Logistic Regression
- Jupyter Notebook

## Approach

The project followed the following general workflow:

1. Loaded and inspected the dataset.
2. Explored the data using Pandas and performed basic statistical analysis.
3. Checked the dataset for missing values.
4. Separated the input features from the target variable.
5. Divided the dataset into training and testing sets.
6. Trained a Logistic Regression classification model using Scikit-learn.
7. Evaluated the model using training and test accuracy.
8. Implemented a simple prediction workflow that accepts individual patient information and produces a classification result.

## Results

The model was evaluated using training and test accuracy to observe its classification performance on the available data.

This project provided practical experience with the basic machine learning workflow from exploring structured data through model training and evaluation.

## Key Learning

Through this project, I gained hands-on experience with:

- Working with structured datasets using Pandas
- Performing basic data exploration and statistical analysis
- Preparing data for machine learning
- Training a Logistic Regression classification model
- Evaluating a classification model using accuracy
- Building a simple prediction workflow using a trained model
