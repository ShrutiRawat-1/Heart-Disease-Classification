# Heart Disease Classification Using Logistic Regression

## Project Overview

This project explores the use of supervised machine learning to classify the presence of heart disease based on patient health and diagnostic attributes.

The project was developed to gain practical experience with data exploration, preprocessing, machine learning model training, and evaluation using Python and Scikit-learn.

## Objective

The objective of this project was to build a basic classification model using Logistic Regression and understand the workflow involved in developing a machine learning model for a binary classification problem.

## Dataset

The dataset contains 303 patient records with 13 input features and one target variable indicating the presence or absence of heart disease.

Basic data inspection, descriptive statistics, and missing-value checks were performed before developing the model.

## Tools & Technologies

- Python
- Pandas
- Scikit-learn
- Logistic Regression
- Jupyter Notebook

## Approach

The project followed the following general workflow:

1. Loaded and inspected the dataset using Pandas.
2. Explored the data through basic statistical analysis.
3. Checked the dataset for missing values.
4. Examined the distribution of the target variable.
5. Separated the input features from the target variable.
6. Divided the dataset into training and testing sets using an 80/20 split.
7. Trained a Logistic Regression classification model using Scikit-learn.
8. Evaluated the model using training and test accuracy.
9. Implemented a simple prediction workflow using individual patient input data.

## Results

The Logistic Regression model achieved:

- **Training Accuracy:** 85.12%
- **Test Accuracy:** 81.97%

The model was also used to generate a classification prediction for an individual set of patient attributes.
